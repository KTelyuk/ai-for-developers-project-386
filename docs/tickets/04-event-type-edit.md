# 04. Редактирование типа встречи

Status: ready-for-agent
Blocked by: 03

## Что сделать

Владелец в `/admin/event-types` открывает тип встречи и меняет название, описание и длительность. Гость сразу видит новые данные. Эндпоинт `PATCH /api/admin/event-types/{id}` по `docs/spec.md`. Изменение длительности действует только для новых записей: это правило проверится в срезе бронирования (тикет 07).

## Критерии приёмки

- [ ] Форма редактирования заполнена текущими значениями, длительность — из списка.
- [ ] Частичное изменение (например, только описание) сохраняет остальные поля.
- [ ] Невалидные значения — `400` с `VALIDATION_ERROR`, неизвестный `id` — `404`.
- [ ] После сохранения список владельца и список гостя показывают новые данные.
