# 13. End-to-end на Playwright

Status: ready-for-agent
Blocked by: 08, 09, 10, 12

## Что сделать

Сценарии из README («Тестирование», шаг 7) в браузере против собранного контейнера, на профилях десктопа (1280 × 800) и телефона (эмуляция iPhone и Android), время фиксируется через часы браузера. Прогон в CI после сборки образа.

## Критерии приёмки

- [ ] Владелец создаёт и редактирует тип встречи.
- [ ] Гость записывается, и запись появляется у владельца.
- [ ] Второй гость не может занять то же время.
- [ ] Гость отменяет запись по ссылке, и время снова свободно.
- [ ] Владелец отменяет запись из своего списка.
- [ ] В гостевом интерфейсе нет ссылок на `/admin`.
- [ ] Все сценарии проходят на обоих профилях локально и в CI.
