# 06. Календарь на 14 дней со счётчиками

Status: ready-for-agent
Blocked by: 05

## Что сделать

Гость выбирает день в календаре окна записи. У каждого дня видно число свободных слотов; выходные, прошедшие дни и дни без слотов неактивны. Эндпоинт `GET /api/event-types/{id}/availability?from&to` по `docs/spec.md` использует тот же модуль расписания. Раскладка по README «Устройства»: на ПК информация, календарь и слоты в три колонки, на планшете «Информация» сверху и две колонки, на телефоне блоки по шагам.

## Критерии приёмки

- [ ] Календарь показывает ровно 14 дней начиная с сегодняшнего по Алматы, окно сдвигается с датой.
- [ ] Счётчик каждого дня совпадает с числом слотов этого дня.
- [ ] Выходные и дни без слотов неактивны и не выбираются.
- [ ] Диапазон длиннее окна — `400`; дни вне окна — 0.
- [ ] Дни календаря не меньше 44 × 44 px.
