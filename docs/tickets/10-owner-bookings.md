# 10. Встречи владельца и отмена

Status: ready-for-agent
Blocked by: 07

## Что сделать

Владелец в `/admin/bookings` видит ещё не закончившиеся встречи всех типов одним списком по времени начала: тип, дата, время, имя и email гостя. Кнопка «Отменить» с подтверждением удаляет любую запись, время освобождается. Эндпоинты `GET /api/admin/bookings` и `DELETE /api/admin/bookings/{id}` по `docs/spec.md`. Навигация между `/admin/event-types` и `/admin/bookings`.

## Критерии приёмки

- [ ] Закончившиеся встречи в список не попадают, идущие сейчас — попадают.
- [ ] Порядок — по возрастанию начала, независимо от типа встречи.
- [ ] Отмена владельцем работает и для уже начавшейся встречи; несуществующая запись — `404`.
- [ ] Без встреч виден понятный пустой список.
