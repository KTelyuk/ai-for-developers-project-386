# 12. Раздача фронтенда и Docker-образ

Status: ready-for-agent

## Что сделать

Сервис собирается в один Docker-образ и запускается в контейнере. Бэкенд раздаёт собранный фронтенд, все неизвестные не-API пути отдают `index.html`. Многоэтапный `Dockerfile` на `node:24-alpine`: генерация, сборка фронтенда, финальный образ только с продакшен-зависимостями; `.dockerignore`; `HEALTHCHECK` на `/api/health`; порт из переменной `PORT`. CI собирает образ, запускает контейнер и ждёт здоровья.

## Критерии приёмки

- [ ] `GET /` и, например, `GET /book` в контейнере отдают приложение; `GET /api/health` — `200`.
- [ ] Неизвестный путь `/api/...` по-прежнему возвращает `404` в формате ошибки, а не `index.html`.
- [ ] Контейнер становится healthy; CI проверяет это на каждый push.
- [ ] В контейнере время слотов совпадает с локальным (смещение `+05:00`).
