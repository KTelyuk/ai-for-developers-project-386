# 11. Состояния и проверка на телефоне

Status: ready-for-agent
Blocked by: 06, 08, 09, 10

## Что сделать

Довести все экраны гостя и владельца до README «Устройства» и состояний: загрузка, пустые списки, ошибки сети с возможностью повторить. На телефоне кнопки «Назад» и «Продолжить» закреплены внизу экрана.

## Критерии приёмки

- [ ] Каждый экран с запросом показывает загрузку и ошибку сети; тесты экранов проверяют их через MSW.
- [ ] На ширине 360 px нет горизонтальной прокрутки ни на одном экране.
- [ ] Нажимаемые элементы — не меньше 44 × 44 px.
- [ ] На телефоне «Назад» и «Продолжить» закреплены внизу и не перекрывают содержимое.
- [ ] Покрытие фронтенда не ниже 80 %.
