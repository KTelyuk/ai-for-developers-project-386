# 08. Конфликт и одновременные брони

Status: ready-for-agent
Blocked by: 07

## Что сделать

Если время успели занять, гость при подтверждении видит сообщение о конфликте, слоты и счётчики обновляются, и он выбирает другое время, не начиная бронирование заново. Из нескольких одновременных запросов на одно или пересекающееся время успешен ровно один.

## Критерии приёмки

- [ ] Тест API: параллельные брони одного времени и пересекающегося времени — ровно один `201`, остальные `409`.
- [ ] При `409` гость остаётся на шаге бронирования с введёнными именем и email, видит сообщение и обновлённые слоты.
- [ ] Занятый слот исчезает из списка после конфликта.
