# 01. Главная страница

Status: done

## Цель

Гость открывает сервис, понимает, что это и как записаться, и одной кнопкой переходит на страницу бронирования.

## Что сделать

- Маршрутизация на React Router: `/` — главная, `/book` — страница бронирования.
- Главная:
  - шапка с названием сервиса «Календарь звонков»; то же название в `<title>`;
  - заголовок и короткое описание: запись на звонок без регистрации;
  - блок «Как это работает» из трёх шагов: выбрать тип встречи → выбрать день и время → оставить имя и email и получить ссылку на запись;
  - кнопка «Записаться», ведёт на `/book`.
- `/book` — заглушка «Скоро здесь можно будет записаться» со ссылкой на главную. Само бронирование — в следующих тикетах.
- Убрать с экрана статус `/api/health` из каркаса.
- Тестовый стек фронтенда: Vitest + Testing Library + jsdom; тесты фронтенда входят в `mise run test` (а значит, в `mise run check` и CI).

Вне тикета: данные из API на главной, профиль владельца, TanStack Query.

## Критерии приёмки

- На `/` видны название сервиса, описание, три шага и кнопка «Записаться».
- Нажатие «Записаться» открывает `/book` без перезагрузки страницы.
- На `/book` видна заглушка и ссылка, возвращающая на главную.
- В гостевом интерфейсе нет ссылок на `/admin`.
- Страница не делает запросов к API.
- Вёрстка адаптивная: на ширине от 360 px нет горизонтальной прокрутки, кнопка не меньше 44 × 44 px.
- Интерфейс на русском языке.
- `mise run check` проходит.

## Тесты

- Компонентный тест главной: заголовок, описание, три шага, кнопка «Записаться».
- Тест маршрутизации: клик по «Записаться» показывает заглушку `/book`; ссылка из заглушки возвращает на главную.
- Тест: на главной и на `/book` нет ссылок, ведущих на `/admin`.
