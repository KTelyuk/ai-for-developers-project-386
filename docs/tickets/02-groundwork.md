# 02. Подготовка: часы, ошибки, моки API

Status: ready-for-agent

## Что сделать

Подготовить общий фундамент, на который опираются все следующие срезы, не меняя поведения для пользователя (см. «Архитектура» и «Testing Decisions» в `docs/spec.md`):

- функция сборки приложения принимает часы — источник «сейчас» — и тесты могут их зафиксировать;
- хранилище в памяти для типов встреч и записей с интерфейсом, который можно заменить на базу;
- единый формат ошибки `{ code, message }` для всех ответов `4xx`, включая ошибки валидации запроса из OpenAPI и неизвестные пути API;
- на фронтенде — TanStack Query и MSW для моков HTTP в тестах; проверка «главная не делает запросов» переведена на MSW (ADR 0002);
- пороги покрытия в конфигах тестов: не ниже 80 % для бэкенда и фронтенда.

## Критерии приёмки

- [ ] Тест API с фиксированными часами проходит через функцию сборки приложения.
- [ ] Запрос к неизвестному пути `/api/...` возвращает `404` с телом `{ code: "NOT_FOUND", message }`.
- [ ] Тесты главной и `/book` проходят на MSW; главная по-прежнему не делает запросов.
- [ ] `mise run check` падает, если покрытие ниже порога.
- [ ] `mise run check` проходит.
